# Methodological overview

PyEvoc operationalises a computational adaptation of the Hierarchical Evocation Method for observational textual corpora. The package separates corpus construction, linguistic preprocessing, token-level foregrounding, term-level diffusion and salience indices, quadrant assignment, and reporting.

The package is designed for transparent research workflows rather than black-box automation. Each module can be run independently and inspected before proceeding to the next step.
