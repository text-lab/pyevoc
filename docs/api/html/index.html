PyEvoc API Reference#

Computational Hierarchical Evocation Analysis

This reference documents every public module, class, and function in PyEvoc 0.2.1 — from dataset ingestion and multilingual preprocessing through feature construction, representational analysis, temporal diagnostics, and publication-quality visualisation.

PyEvoc 0.2.1 Python 3.9+ MIT License Sphinx API

Core package areas#


pyevoc.data
Dataset loading, schema standardisation, date filtering, and metadata preservation.

pyevoc.preprocessing
Language filtering, thematic filtering, corpus statistics, text cleaning, and linguistic annotation.

pyevoc.features
Foregrounding, emoji assignment, unigram selection, term indices, concreteness, and emoji labelling.

pyevoc.analysis
EVOC quadrant assignment, collocation and entity analysis, and temporal stability diagnostics.

pyevoc.visualisation
Publication-oriented and interactive plots for EVOC maps, semantic trees, emojis, and temporal Sankey flows.

pyevoc.config
Configuration dataclasses, package-level defaults, and runtime settings.

pyevoc.utils
Utility functions for I/O, bundled resource access, validation, and shared helpers.

pyevoc.models
Bundled lexicons, emoji lookup tables, and anchor word lists shipped with the package.
